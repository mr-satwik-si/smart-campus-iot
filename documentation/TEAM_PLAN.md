# Four-Member Team Plan
| Member | Workstream | Deliverables |
|---|---|---|
| 1 | IoT hardware and firmware | ESP32, entry sensors, energy meter integration, physical test evidence |
| 2 | Backend and API | Express routes, validation, authentication and API tests |
| 3 | Frontend | Responsive dashboard, occupancy view, power trend and usability |
| 4 | Database, integration and documentation | SQLite, integration tests, architecture, report and presentation |

## Checkpoints
1. Software demo runs and health endpoint returns ok.
2. Demo readings appear on dashboard and persist after restart.
3. Device POST authenticates and stores a hardware-source reading.
4. Compare occupancy estimate with manual counts and meter values with a reference meter.
5. Final demonstration labels simulated versus measured output clearly.

Each member should commit their own contribution and retain test evidence. Do not report a hardware feature as completed until physically tested.
